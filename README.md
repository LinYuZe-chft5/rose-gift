# Rose Apology

一个无需联网、自动播放的手机竖屏艺术动画。第一页以星空、星轨玫瑰和渐显文案构成；轻触后转入暖阳下的金毛犬花海场景。

## 文件

- `index.html`：原有星轨玫瑰及第二场景的最小接入点。
- `golden-meadow.css`：金毛花海场景的响应式布局、转场和微动画。
- `golden-meadow.js`：SVG 金毛主体、固定种子 Canvas 花海和环境动画。
- `css/style.css`、`js/main.js`：项目中保留的另一版玫瑰实现，当前根入口不引用。

## 运行

可以在 VS Code 中直接打开 `index.html`，现代浏览器即可运行。更接近手机浏览器的方式是在项目目录启动静态 HTTP 服务：

```text
python -m http.server 8000
```

电脑浏览器访问 `http://localhost:8000`。若要用 Android 手机访问，电脑和手机连接同一 Wi-Fi，在电脑上查找局域网 IPv4 地址，然后在手机访问 `http://电脑局域网地址:8000`。

## 使用

打开后无需点击即可观看星轨玫瑰。轻触玫瑰页面会平滑进入金毛犬花海。开发时可用 `?scene=meadow` 直接预览第二场景。

## 兼容性与限制

项目不使用第三方依赖、远程资源、音频或构建工具。桌面浏览器和 Android Chrome 是目标环境。字体外观和地址栏高度由设备控制，建议在真实手机上最终确认排版与观感。开启“减少动态效果”后，非必要转场、呼吸和眨眼动画会停用或快速完成。
